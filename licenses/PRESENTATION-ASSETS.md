# Источники изображений презентационного каталога

Файл `apps/api/live/presentation-assets.json` содержит названия и изображения предметов Dota 2, Rust и Team Fortress 2 для презентации: 43, 43 и 45 предметов соответственно. Он не содержит ни цен, ни данных о наличии и не является каталогом поставщика.

Названия и адреса получены из публичных страниц отдельных предметов [Steam Community Market](https://steamcommunity.com/market/) и публичного ответа `market/search/render/` с параметром `norender=1` для идентификаторов игр 570, 252490 и 440. Для каждого предмета сохранялись только `market_hash_name` и `icon_url`, а изображения размещены на `community.steamstatic.com`. Информация об остатках и ценах из ответа не сохранялась.

У первых 24 изображений (по восемь на игру) проверен ответ `200 image/png`; остальная часть использует адреса, полученные непосредственно из ответа Steam, но не проверялась по одному. Картинки загружаются с CDN Steam и зависят от доступности его сервиса и подключения пользователя. При необходимости распространения и коммерческого использования следует проверить права и условия источника.
# Расширенный локальный справочник

Для презентации CS2 дополнен индексом [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API), закреплённая ревизия `7c18f4c4daf42706199055712c1a7b267b7e0db6`: категории `skins_not_grouped`, `stickers`, `keychains`, `agents`, `crates`, `keys`, `patches`, `graffiti`, `music_kits`, `collectibles`. Импорт включает только рыночные имена с проверенными по формату ссылками Steam CDN, без цен, количества и наличия. Варианты с одинаковым именем и разными изображениями сохраняются отдельно. `node --import tsx scripts/import-presentation-cs2.mts` повторяет импорт той же закреплённой версии.

Справочник Dota 2 включает имена из [EricZhu-42/SteamTradingSite-ID-Mapper](https://github.com/EricZhu-42/SteamTradingSite-ID-Mapper), ревизия `aef613acaf3cae7f1e0c286240df9245e3246be4`, лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Преобразование сохраняет только названия, удаляя сторонние идентификаторы, цены и прочие поля. Повторный импорт: `node --import tsx scripts/import-presentation-dota.mts`. Авторы не гарантируют полноту и актуальность. Изображение остаётся пустым, кроме ранее сопоставленных имён с подтверждённой ссылкой Steam; изображения не угадываются.

Дополнительные изображения Dota можно получить ограниченными порциями из публичного поиска Steam: `node --import tsx scripts/import-presentation-steam-dota.mts 5`. За один ручной запуск запрашиваются максимум 5 страниц по 10 записей с паузой 5 секунд; запуск по расписанию не настроен. Скрипт запоминает прогресс в `presentation-dota-import-state.json` и атомарно сохраняет только полное успешное обновление `presentation-dota-images.json`. При 429/503 он останавливается и учитывает `Retry-After`; не запускайте снова до указанной паузы. Отображаемые имена и значки берутся только из совпадающих полей ответа Steam без цен и остатков. Порядок и состав выдачи Steam меняются, поэтому обход с возобновлением не доказывает полноту: возможны повторы, пропуски и исчезнувшие позиции. Текущий результат: 50 полученных Steam записей, из них 31 новая картинка по сравнению с предыдущими 43; всего картинка есть у 74 предметов Dota. Остальные названия остаются с заглушкой.

Эти наборы — определения предметов, а не предложения конкретных продавцов. Они не гарантируют реальную торговую доступность на RED DROP или у Skinslink. Источники Valve и Steam не публикуют тем самым гарантию абсолютной полноты.
